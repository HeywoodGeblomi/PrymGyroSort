## License and CLA

This project is dual-licensed (AGPLv3 + Commercial). Copyright is held solely by Heywood Geblomi.

Before any external pull request is merged, contributors must sign a Contributor License Agreement (CLA) / Copyright Assignment Agreement that grants the project the right to re-license contributions under both the AGPLv3 and the commercial license.

Until the CLA Assistant (or equivalent) is active on the organization:

- External PRs that touch licensed source will be closed with a request to complete the CLA.
- Trivial documentation-only fixes may be accepted at the maintainer's discretion.

## Code

- Ranker stays a library. No second kernel. χ default off.
- Independent verification and stranger path must remain green.
- Read NON_CLAIMS.md before proposing feature expansion.

## Process

1. Open an issue describing the change.
2. Fork, branch, implement.
3. Ensure tests pass.
4. Submit PR and complete CLA when prompted.
